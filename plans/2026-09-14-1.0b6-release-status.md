## Pitfalls for the next session

- **Ask before heavy work.** The user works on the same laptop. Check before running builds,
  archives, full test suites or multi-agent runs.
- **The pre-push hook fails on coverage.** `.git/hooks/pre-push` runs
  `scripts/generate_coverage_report.sh`, which runs the full SwiftUI suite. Coverage is
  **25.73%** against a 50% threshold. The user approved `--no-verify` for the 2026-09-14 push
  only. Ask again before each use.
- **Xcode builds reformat source files.** A "SwiftFormat" build phase runs `swiftformat` on
  `SwiftUI/EdgeStudio` every build, so a build can change files nobody edited. Run
  `git status` after any build, and commit formatting-only changes separately.
- **Gradle may skip the tests.** `./gradlew testDebugUnitTest` can report `UP-TO-DATE` and
  reuse old results. Use `--rerun` and check the XML timestamps in
  `android/app/build/test-results/testDebugUnitTest/`.
- **Don't use heredocs in chained zsh commands.** A heredoc inside a `\`-continued
  `git commit` chain produced a commit with no title line. Write the message to a file and
  use `git commit -F`.
